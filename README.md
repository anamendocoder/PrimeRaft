# PrimeRaft

Cloud-based PrimeRaft manager that handles machine learning integration, built for everyday use.

With PrimeRaft, you get a lightweight tool that stays out of your way.

**What you get**

- Cloud-based PrimeRaft manager that handles
- machine learning integration, built for
- everyday use

## Technology Stack

- python

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/PrimeRaft.git`
2. `cd PrimeRaft`
3. Install in editable mode: `pip install -e .`

## Configuration

PrimeRaft is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
